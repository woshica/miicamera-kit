本次通过 41 项工作台相关测试及 JavaScript 语法检查。浏览器在隔离配置与模拟进程下验证了详细画面保存、另存方案、一分钟试录入口、录制期间参数锁定及停止后恢复；没有连接现场相机或实际编码录像。桌面、900 像素与 390 像素宽度下检查布局无横向溢出，小屏详细配置对话框可操作。正式工作台已刷新到新布局，现场配置未更改。上述验证不替代客户电脑上的实际短录。
