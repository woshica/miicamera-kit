# 驱动安装与拍摄故障排查

先用工具菜单 2 区分“相机没有被发现”“相机忙”“连接速度低”和“编码失败”。这些问题需要不同的处理，重复安装全部软件通常没有帮助。

| 现象 | 检查与处理 |
| --- | --- |
| 双击 CMD 报 `No module named 'recording_profile'` | 2026-10-21 已修复菜单入口遗漏脚本搜索路径的问题。便携 Python 默认隔离模块路径，更新后的 `deprecated/scripts/menu.py` 会根据自身位置加载同目录模块，不依赖当前目录或系统 Python。若在旧副本上复现，请复制完整更新后的工具包；原厂 ImageView 不受此脚本错误影响。 |
| `Expected exactly one camera; found 0` | 检查数据线、电源和 USB 插口；拔插后重新自检。设备管理器有感叹号时，使用原厂安装程序安装驱动。 |
| 找到多台相机 | 目前自动录像脚本只处理一台；暂时仅连接本次要用的相机。 |
| 找到相机但无法打开 | 关闭 ImageView 实时窗口、OBS 或其他占用相机的软件，再试。 |
| 型号后缀有 `(USB2.0)` | 用合格 USB3 线直连 USB3 口，检查相机端插头是否插到底、扩展坞和延长线是否降速；重新自检。设备名称含 USB3 不证明实际链路是 USB3。 |
| 30 fps 录像被拒绝 | 在 USB2 连接上，这是预检的正常保护。换成 USB3 后再试；低帧率诊断不等于正式记录。 |
| USB3 已连接，但请求 30 fps 只得到约 20 fps | 本机已复现 SDK 软件限帧导致跳帧。当前工具以速度档位 2、`sdk_frame_rate_limit=0` 获取原生约 30 fps；45 fps 使用速度档位 4。不要把 SDK 软件限帧数值直接设为目标录像帧率。 |
| 手动 10 ms 画面太暗 | 检查镜头盖、光圈、目标照明。先在 ImageView 看画面，再调整配置中的曝光和增益；曝光加长会增加运动拖影并可能限制帧率。 |
| ImageView 菜单仍为英文，或侧栏分组标题、首选项导航出现空白 | 先检查目录层级：`runtime/imageview/x64/` 中应有 `imageview.exe` 及同目录 DLL；`i18n/`、`help/`、`imageview.exml`、`imageview.dye` 应位于上一级 `runtime/imageview/`。程序和共享资源放在同一级会导致语言资源找不到；恢复原厂层级后重启。若仅需切换语言，在「选项 → 首选项 → 杂项 → 语言」选择 **Simplified Chinese（简体中文）**，保存后重启。 |
| 日间画面偏红或颜色不准 | 在稳定白光下用中性白/灰目标做白平衡，并核对 NIR 版本的滤片。不要以软件灰度转换替代光学和照明验证。 |
| `Encoder queue overflow` 或帧率不足 | 查看日志，尝试可用的 NVIDIA 硬件编码、关闭其他高负载任务并检查 USB3/存储。异常记录保留供检查，不能当作合格记录。 |
| 45 fps 帧号跳变、SDK 前/后端队列满 | 当前工具已使用前后端各 16 帧、USB 接收线程优先级 2，并连续编码分段，已通过本机 5 分钟 45 fps 软件录像。核对是否使用更新后的脚本及配置，再复测；单纯加大缓冲或软件丢帧计数为零都不足以证明完整。对照证据及商家询问稿见 [诊断记录](diagnosis-and-vendor-questions.md)。 |
| NVIDIA 编码失败 | 目标电脑可能没有兼容NVIDIA显卡或驱动。先检查实际显卡、驱动和日志，修复后重试；本包没有附带显卡驱动安装器。不要直接改成CPU CRF21并假定仍能录4K45，本机该路径已有吞吐不足记录。 |
| 磁盘空间不足、掉线或 2 秒无帧 | 程序停止并标记未完成；检查空间和连接，修复后启动新的记录。脚本不会自动重连或覆盖旧文件。 |

## 什么时候安装驱动

本机在系统级安装前已经使用 Microsoft WinUSB 成功打开相机，因此保留该驱动。客户电脑若能通过菜单 2 并拍到照片，也无需重复安装。

需要安装时，退出相机软件并运行 `installers/MIIImageViewSetup.exe`，由现场管理员完成 Windows 管理员提示和原厂安装向导。不要关闭系统安全功能。完成后重新插接设备并执行自检、拍照。

`installers/MIIDshowSetup.exe` 仅供以后需要通过 DirectShow 连接 OBS、第三方录像软件时使用；本包 SDK 录像不需要它。TWAIN 是图像采集软件接口，本流程未使用，故没有额外安装。网站中的 Miinam 网络相机包用于另一类设备，本 USB 相机没有使用。

三个商家二进制包的 SHA-256 已与同版本 `hash.txt` 核对；详情在 `docs/package/sources.json`。两份商家安装 EXE 本身未带 Authenticode 签名。迁移时保留原始安装包和校验记录；需要升级时另建版本目录并重做连接、画质和录制验证。
