# ImageView 小鼠录像设置：现场试拍起点

> 本文中的命令、配置和资源路径均相对于软件包根目录 `miicamera-kit/`；辅助入口在 `test/`，旧方案入口在 `deprecated/test/legacy/`。

**2026-10-25 更新：主要录制方式为官方 ImageView，使用用户已认可的 MP4／H.265、质量100。** 操作与长录功能边界见 [官方录制流程](../deprecated/docs/official-recording-workflow.md)。下文关于 `mouse-4k45-recommended.json`、24/26 Mbps、CSV及907 GB的内容属于原脚本方案，不能当作官方录像设置或容量要求。

对象为 IP108300D / E3ISPM08300KPD 配 8 mm 镜头。核对日期：2026-10-19。**下列均为试拍起点，尚非小鼠实验验证标准。**[随包中文手册](../runtime/imageview/help/hans.pdf)和[英文手册](../runtime/imageview/help/en.pdf)描述通用 ImageView 功能；每项须以本型号当前 GUI 可见性、读回值和实际录像验收。下文中文 PDF 页与手册印刷页脚相同。GUI 与 SDK 设置独立；此前 SDK 路径 4K、45 fps、10 ms 录 5 分钟通过，不能证明 ImageView 同样稳定，也不能证明 45 fps 足以捕捉所有快速动作。

| 必做 | 白天用中性白/灰参照物执行一次白平衡，然后关闭持续自动白平衡，固定色温/Tint。 | 在正式照明、不过曝的参照物上校准；红框是白平衡取样区。[中 PDF/印刷 20](../runtime/imageview/help/hans.pdf) §4.4。本型号已有记录支持色温/Tint，而 RGB 增益白平衡读取返回未实现，不建议为此切换到 RGB 白平衡模式。 |
| 必做 | 亮度、对比度、伽马、色调、饱和度先保持默认并记录；直方图界限先用 **0–255**，不反复点“自动”。 | 直方图“自动”会重新设置映射边界，不只是查看统计。检查白鼠/反光处不过曝、黑鼠/阴影内仍有轮廓；不要求直方图必须居中。[中 PDF/印刷 21、24](../runtime/imageview/help/hans.pdf) §4.6、4.16。 |
| 建议 | 额外锐化先设 **0/关闭**，若确有收益再试低档；可调降噪先保守，不把边缘变锐当作对焦完成。 | 原厂手册说明锐化最左端为禁用。[中 PDF/印刷 25](../runtime/imageview/help/hans.pdf) §4.19。通用工业成像资料提示强降噪可能抹去细结构，但不据此推断本型号具体降噪算法。[Basler 说明](https://docs.baslerweb.com/pgi-feature-set)。 |
| 必做 | 预览用 **3840×2160、RGB24**；有位深选项时先用 8 位路径。全幅 ROI，数字 Binning 数量 **1**。 | RGB24 为每色通道 8 位；RAW/RGB48、12 位不是达到 4K 45 fps 的必要条件，切换后需要重新验证性能。数字 Binning 会缩小图像尺寸。[中 PDF/印刷 18–19、21、23](../runtime/imageview/help/hans.pdf) §4.2、4.7、4.15。 |
| 必做 | 帧率滑块取稳定较高档，目标 45 fps，核对实际录像；只有确有带宽/处理瓶颈时才单独试硬件 ROI，保证整个活动区域在框内。 | 预览分辨率、录像分辨率、实际帧率分别核对。[中 PDF/印刷 22–23](../runtime/imageview/help/hans.pdf) §4.9、4.14。本型号有硬件 ROI 能力，但不能预先保证裁剪后的帧率。 |
| 必做 | 普通连续录像，关 Time-lapse；若向导有帧率倍数，选正常时间 **x1**，核对时间限制。沿用用户已认可的 MP4/H.265、质量100，检查时长、文件大小和写盘。 | [中 PDF/印刷 63–65、134](../runtime/imageview/help/hans.pdf) §10.3、15.1.2。旧手册列 MP4/H.264、H.265，质量1–100、默认100；**当前 UI 为25–100，以当前可输入范围为准**。质量100不等于已证实无损。手册倍率是录像时序选项，不能当采集fps；“快速录像”会继承上次编码和延时设置。H.265已在本机样片中确认，客户机仍检查实际编码器与试录结果。 |

若使用随包自动录像工具，菜单 **5** 是旧通用入口，继续读取 `deprecated/config/capture-defaults.json`，仍为 300 秒分段且无本推荐配置的码率限制；下述 1 小时分段和容量预算只适用于菜单 **10/11** 与两个快捷方式「deprecated/test/legacy/按推荐配置录制.cmd」「deprecated/test/legacy/推荐配置试录60秒.cmd」。菜单 **10** 默认计划时长 72 小时，菜单 **11** 使用同一配置但时长为 60 秒。配置见 [README 自动录像说明](../deprecated/docs/完整使用说明.md#自动录像与设置) 和 [推荐 JSON](../deprecated/config/mouse-4k45-recommended.json)。推荐值为 4K、45 fps、曝光 10 ms、增益 100（SDK 百分比）、3600 秒分段、GOP 45 帧、B 帧 0；编码器自动选可用 NVENC，否则回退到 libx264。使用 capped VBR，目标码率 24 Mbps、最大 26 Mbps、VBV 缓冲 52 Mbit；两种编码器路径都应用目标码率与上限，不使用 CRF/CQ（仅 quality 模式使用这些字段）。FFmpeg 的 `maxrate`、`bufsize` 见[官方编码器选项](https://ffmpeg.org/ffmpeg-codecs.html#Codec-Options)。该推荐路径会在开相机前校验配置；除降噪外，其余配置列出的成像字段会尝试写入并读回核验，已在 2026-10-19 的 60 秒推荐配置实机短录中完成读回核验。本型号 `get_Option(DENOISE)` 探测返回 `E_NOTIMPL`，JSON 中 `denoise: null` 表示脚本不控制额外降噪，不能据此称为已关闭。JSON 不是 GUI 参数导入文件，ImageView 仍须按本页单独设置。当前 capped VBR 配置另已通过 60 秒 NVENC 实机短录：2710 帧、45.2087714 fps，帧缺口、软件丢帧及缓冲溢出均为 0，临时 20 秒分段均完整解码；这不替代正式 3600 秒分段的等待验证或 72 小时长录。短录运行文件外推约 818.0 GB，属于容量估算而非长录实测。容量预算约需 907.25 GB；950 GB 是约每 2 秒及收尾检查的保护阈值，触发后停止并标记 `incomplete`，不是精确上限，也不保证录满 72 小时。限码率压缩可能更强，须在夜间与快速细节场景检查画质。

其余按实际问题调整：

- 有交流灯横纹时试 **50 Hz**，稳定直流光源试 DC；手册说明防闪烁与自动曝光联动，固定手动 10 ms 不能保证去除 LED PWM 条纹。每个日/夜调光档各验收。[中 PDF/印刷 22](../runtime/imageview/help/hans.pdf) §4.8。
- 日夜先分别校准并固定曝光；如需自动曝光应单独试验，同时限制最大曝光和最大增益。45 fps 每帧约 22.2 ms，曝光上限需留余量且满足运动清晰度；不能保留数百毫秒上限而期望维持 45 fps。手册列最大曝光选项 10–5000 ms、默认 350 ms，最大增益 100–5000%、默认 500%；这些是旧版通用软件选项，**不是本型号上限或建议值**。[中 PDF/印刷 139](../runtime/imageview/help/hans.pdf) §15.1.8.4。
- 翻转/旋转只为坐标方向一致，定后固定。[中 PDF/印刷 22](../runtime/imageview/help/hans.pdf) §4.11–4.12。降采样与数字 Binning 默认不用；后者是电脑软件处理，不能许诺传感器读出、USB 传输或 fps 提升。[中 PDF/印刷 23](../runtime/imageview/help/hans.pdf) §4.13–4.15。
- 黑平衡、暗电平、转换增益先留默认；黑鼠和笼内阴影不应被用作黑平衡参照。暗场/平场仅在固定噪声或亮度不均影响判读时试，建议按实际分辨率、曝光、增益与照明重建校准；平场需均匀参照，不能把有动物或复杂笼具的场景当作均匀背景。保留出厂坏点处理默认。[中 PDF/印刷 21、24–25](../runtime/imageview/help/hans.pdf) §4.5、4.17–4.18。实时 FPN、动态坏点、降噪的具体算法未由该手册说明；“处理 > 去噪”属于图像后处理，不能当作录像控制。
- 日夜分别保存侧边栏“预设/参数”并回载核对；它不保证保存录像向导设置，也不会因此自动按时间切换。夜间红外重新检查对焦、曝光和噪声；可试灰度，但去色不能增加传感器感光能力，也不能替代红外光学验证。[中 PDF/印刷 22、25–26、134](../runtime/imageview/help/hans.pdf) §4.10、4.21、15.1.2。
- 手册录像时限默认 **60 秒**，到时停止，不等于自动分段。需长期录像时核对时限或使用已搭建的分段工具。若 ImageView 枚举到 NVIDIA 编码，可与软件编码短测对比；脚本中 NVENC 测试通过不证明 GUI 的同名编码器已通过。视频逐帧时间戳及分段连续性须检查实际输出。[中 PDF/印刷 64–65](../runtime/imageview/help/hans.pdf) §10.3。

本型号与工具的界限：菜单 5 的旧脚本路径设置曝光、增益、速度与 RGB24，但不固定或记录伽马、对比度、锐化等成像字段；菜单 10/11 的推荐配置路径会尝试设置并逐项读回核验其 JSON 中列出的 8 位、binning、全幅 ROI、伽马、对比度、亮度、色调、饱和度、锐化、Temp/Tint 白平衡和电平范围，这些字段已通过 60 秒实机短录的写入与读回核验。SDK 对 `get_Option(DENOISE)` 的只读探测返回 `E_NOTIMPL`，推荐 JSON 的 `denoise: null` 表示脚本不控制额外降噪，不能宣称已关闭。配置中的 Temp 6503、Tint 1000 是待现场校准值，既非已校准白平衡，也非昼夜自动方案。原厂 GUI 与两条脚本路径分别配置，不能假定处理结果相同；配置仅控制实际实现的字段。镜头对焦与光圈仍需机械调整。依据：[SDK 定义](../sdk/python/miicam.py)、[采集脚本](../scripts/capture.py)、[本机验证记录](local-verification.md)。[厂家型号列表](https://www.touptekphotonics.com/Microscopy/E3ISPM/)列出该型号为卷帘快门、4K 45 fps；更短曝光仍不能把它变为全局快门。

**验收**：日、夜和切灯场景各录含静止、快跑/转身、靠边活动的短片，再按目标时长连续录一段；逐段看视野、拖影、噪声、条纹、亮度跳变、细结构，核对输出宽高、首中末帧间隔、单调时间戳、掉/重帧、墙钟与播放时长、文件结尾及分段衔接。达到本机试拍要求后才锁定方案；行为需要更短时间尺度时重新评估帧率和曝光。
